Design system

The tokens and components this site is built from. They follow Google's Material Design 3 values (type scale, shape scale, state layers and component sizes) with the site's own fonts and colours, and Chrome's modern web guidance for accessibility and CSS. Change a token in styles.css and every page follows.

Colour roles

Material 3 role names. Each role holds a light and a dark value, combined with light-dark(), so the page follows the system theme unless the switch pins one.

Type scale

Material 3 sizes in rem with unitless line heights, so text follows browser and system text size. Headings balance their lines; paragraphs avoid single-word last lines.

Space and shape

A 4dp spacing grid. Corners: 4 (table), 8 (chips), 12 (cards), 16, 28 and full (buttons). Layout follows the Material window classes: compact under 600px, medium to 840px, expanded above, written in em so they respect text scaling.

Flows

Processes are drawn as a rail of steps in reading order, built as an ordered list so screen readers get the same sequence. The rail fills in as you scroll using CSS scroll-driven animations; with reduced motion, or in browsers without support, it shows complete. Steps where I decide carry my logo; steps done by agents carry a dot.
